## 试试这些功能

1. **📖 阅读进度追踪** — 浏览几个页面后关闭标签页，重新打开看看"继续阅读？"提示
2. **📍 滚动位置记忆** — 在长页面滚动到中间，切到其他页面再切回来
3. **✅ 侧边栏已读标记** — 查看左侧 Sidebar 的 ✓ / ○ 标记
4. **⏱ 阅读时间预估** — 每页正文上方会显示预估阅读时间
5. **⬆ 回到顶部按钮** — 向下滚动 300px 后右下角会出现浮动按钮
6. **📋 代码块复制** — 鼠标悬停在代码块上会显示复制按钮
7. **📊 阅读统计** — 侧边栏顶部显示已读进度
8. **📏 顶部进度条** — 页面顶部有一条基于整本书阅读进度的细线
