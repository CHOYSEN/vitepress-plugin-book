# 进阶用法

## 阅读统计

插件在幕后追踪以下数据：

- **累计阅读页数** — 浏览过的不重复页面数量
- **累计阅读时长** — 页面在前台可见时的累计时间（切到后台自动暂停计时）
- **连续阅读天数** — 基于 UTC+8 时区的自然日连续签到

这些信息可以在浏览器的 DevTools 中查看：

1. 打开 DevTools → Application → Local Storage
2. 找到 `vitepress-book:stats` 键
3. 查看 `readPages`、`totalReadingTimeMs`、`readingDays` 等字段

## 多 Sidebar 配置兼容

VitePress 支持两种侧边栏配置方式：

**数组格式（单侧边栏）：**

```ts
sidebar: [
  { text: 'Guide', items: [...] },
  { text: 'API', items: [...] },
]
```

**对象格式（多侧边栏）：**

```ts
sidebar: {
  '/guide/': [{ text: 'Guide', items: [...] }],
  '/api/':   [{ text: 'API', items: [...] }],
}
```

插件对两种格式都做了兼容处理，会自动提取所有页面链接用于进度计算。

## 与浏览器缩放配合

有用户可能会问：插件为什么不做字体大小调节？因为现代浏览器已经提供了完善的缩放功能
（`Cmd + +/-` 或 `Ctrl + +/-`），再次实现是重复造轮子。

同理，内容宽度调节也可以通过浏览器的阅读模式或缩放来实现。

## 兼容性

- VitePress >= 1.0.0
- Vue >= 3.3.0
- 所有现代浏览器

## 一段长内容让你测试滚动恢复

现在请做一个实验：

1. 记住你在这个页面的滚动位置
2. 点击侧边栏的「基本体验」页面
3. 再点击侧边栏回到这个页面

你应该会回到现在的滚动位置。这就是 `useScrollMemory` 在起作用。

这个功能在阅读长文档时特别有用。比如你在看一个 API 页面，需要跳去另一个页面
确认参数类型，再切回来。没有滚动记忆的话，每次切换都要重新滚动到之前的位置。

实现原理：插件在页面滚动时以 500ms 的频率节流保存 `window.scrollY` 到 localStorage。
当页面重新加载时，在 DOM 渲染完成后（`nextTick + 150ms delay`），恢复保存的滚动位置。

还有一个安全机制：如果 URL 中带有 `#` 锚点（说明用户点击了某个标题链接），
插件会跳过滚动恢复，让浏览器处理锚点定位。这避免了锚点导航和滚动恢复之间的冲突。
